# Gym Hearts im Browser spielen

Das Spiel ist eine statische Webseite ohne Build oder Server-Abhängigkeiten.
Die Startseite im Repository-Hauptverzeichnis führt zum Spiel; dessen Bilder
bleiben relativ zur Spiel-HTML erreichbar.

## Einmalige Aktivierung

Im GitHub-Repository unter Settings → Pages:

1. Bei Build and deployment als Source **Deploy from a branch** auswählen.
2. Branch **main**, Ordner **/ (root)** auswählen und **Save** anklicken.
3. Den ersten Pages-Deployment-Lauf abwarten. GitHub zeigt anschließend die tatsächliche Spieladresse an.

Nach der Aktivierung veröffentlichen weitere Pushes auf main den aktuellen Stand.
Der GitHub-Tarif und die Repository-Sichtbarkeit müssen Pages unterstützen.
Eine veröffentlichte Pages-Webseite kann öffentlich zugänglich sein.

Die Einzeldatei Gym_Hearts_0_1_Test.html lässt sich alternativ herunterladen
und direkt im Browser öffnen.
